# Социальная сеть для путешественников - System Design
Домашнее задания по курсу - [System Design](https://balun.courses/courses/system_design)

## Функциональные требования
- публикация постов с фотографиями, описанием и геотегом
- оценка постов и возможность комментирования другими пользователями
- подписка на путешественников
- поиск мест для путешествий и просмотр постов их этих мест
- просмотр ленты пользователя и других путешественников основанной на подписках (в обратном хронологическом порядке)

## Нефункциональные требования
- DAU 10 000 000 за первый год + дальнейший рост
- Аудитория: страны СНГ
- Активность пользователей
  - Пользователи публикуют 2 поста в месяц
  - В среднем 8 фотографий в посте 
  - Пользователь просматривает 6 постов в день
  - 25% пользователей оставляют оценки к просмотренным постам
  - 10% пользователей оставляют комментарии к просмотренным постам
  - Длина комментария в среднем 30 символов
  - Длина описания поста в среднем 500 символов
  - Вес фото в среднем 1MB
  - Пользователь загружает ленту в среднем 10 раз в день
  - В ленте одновременно загружается 25 постов
  - Пользователь подписывается на других путешественников в среднем 1 раз в неделю
- Есть сезонность. Летом отпуск берут чаще и больше путешествуют.
- Коэффициент сезонности - 1.35
- Хранение постов - всегда
- Лимиты
  - Длина поста не более 3000 символов
  - Длина комментария не более 200 символов
  - Число подписчиков не более 3 000 000
  - Число подписок не более 1000
  - Вес фото не более 5MB 
- Временные ограничения
  - Публикация поста не более 3 секунд 
  - Просмотр поста не более 1 секунды
  - Оценка поста не более 1 секунды
  - Отправка комментария не более 2 секунд
  - Загрузка ленты не более 2 секунд
  - Поиск мест для путешествий не более 3 секунд
  - Подписка на пользователя не более 1 секунды
- Доступность приложения - 99.9% в год (простой не более 8.76 часов в год)

## Оценка нагрузки

### RPS

- Публикация поста = 10 000 000 * 2 / 30 / 86400 = 8 RPS
- Просмотр поста = 10 000 000 * 6 / 86400 = 695 RPS
- Оценка поста = 10 000 000 * 6 * 0.25 / 86400 = 174 RPS
- Комментарий к посту = 10 000 000 * 6 * 0.1 / 86400 = 70 RPS
- Просмотр списка постов = 10 000 000 * 10 / 86400 = 1158 RPS
- Подписка на пользователя = 10 000 000 * 1 / 7 / 86400 = 17 RPS

### Трафик

#### Публикация поста (write)

```
user_id = 16B
title = 30B
description = 3000B
place_id = 16B
images = 8 * 1MB = 8MB

info = 16B + 30B + 3000B + 16B = 3062B
media = 8MB
```

info_traffic = 8 RPS * 3062 = 24KB/s

media_traffic = 8 RPS * 8MB = 64MB/s

#### Просмотр поста (read)

```
post_id = 16B
title = 30B
description = 3000B
place_id = 16B
images = 8MB

info = 16B + 30B + 3000B + 16B = 3062B
media = 8MB
```

info_traffic = 695 RPS * 3062B = 2MB/s

media_traffic = 695 RPS * 8MB = 5.5GB/s


#### Оценка поста (write)

```
user_id = 16B
port_id = 16B
reaction = 1B

info = 16B + 16B + 1B = 33B
```

info_traffic = 174 RPS * 33B = 5.5KB/s


#### Комментарий к посту (write)

```
user_id = 16B
port_id = 16B
message = 200B

info = 16B + 16B + 200B = 232B
```

info_traffic = 70 RPS * 232B = 16KB/s


#### Просмотр списка постов (read)

```
user_id = 16B

Список из 25 постов
post_id = 16B
title = 30B
preview_image = 1MB

info = 16B + 25 * (16B + 30B) = 1166B
media = 25 * 1MB = 25MB
```

info_traffic = 1158 RPS * 1166B = 1.3MB/s

media_traffic = 1158 RPS * 25MB = 28GB/s


#### Подписка на пользователя (write)

```
user_id = 16B
author_id = 16B

info = 16B + 16B = 32B
```

info_traffic = 17 RPS * 32B = 0.5KB/s

## Расчёт ресурсов

Расчёт дисков производитя для 1 года хранения данных.

### Параметры дисков

| Характеристика                   | HDD      | SSD (SATA) | SSD (nVME) |
|----------------------------------|----------|------------|------------|
| Объем                            | до 32TB  | до 100TB   | до 30TB    |
| Операции ввода-вывода в секунду  | 100      | 1 000      | 10 000     |
| Пропускная способность           | 100 MB/s | 500 MB/s   | 3 GB/s     |

### Посты

Сapacity = 24 KB/s * 86 400 * 365 = 0.7 TB
Ожидаемый трафик = публикация поста + просмотр поста + просмотр списка постов = 24KB/s + 2MB/s + 1.3MB/s = 3.3MB/s
Ожидаемый RPS = 8 RPS + 695 RPS + 1158 RPS = 1861 RPS

#### НDD
Disks_for_capacity = 0.7 TB / 1 TB = 1 Disk
Disks_for_throughput = 3.3 MB/s / 100 MB/s = 1 Disk
Disks_for_iops = 1861 / 100 = 19 Disk
Disks = max(1, 1, 19) = 19

#### SSD (SATA) 
Disks_for_capacity = 0.7 TB / 1 ТБ = 1 Disk
Disks_for_throughput = 3.3 MB/s / 500 MB/s = 1 Disk
Disks_for_iops = 1861 / 1000 = 2 Disk
Disks = max(1, 1, 2) = 2


#### Итого: выбираем конфигурацию с 2 SSD (SATA) по 500 GB


### Комментарии

Сapacity = 16 KB/s * 86 400 * 365 = 482GB
Ожидаемый трафик = 16 KB/s
Ожидаемый RPS = 70 RPS

#### НDD
Disks_for_capacity = 482 TB / 500 GB = 1 Disk
Disks_for_throughput = 16 KB/s / 100 MB/s = 1 Disk
Disks_for_iops = 70 / 100 = 1 Disk
Disks = max(1, 1, 1) = 1

#### Итого: достаточной конфигурацией является с 1 HDD на 500 GB


### Реакции

Сapacity = 5.5 KB/s * 86 400* 365 = 166 GB

#### НDD

Disks_for_iops = 174 / 100 = 2 Disk
Disks = max(1, 1, 2) = 2

#### SSD (SATA) 
Disks_for_capacity = 166 GB / 250 GB = 1 Disk
Disks_for_throughput = 5.5 KB/s / 500 MB/s = 1 Disk
Disks_for_iops = 174 / 1000 = 1 Disk
Disks = max(1, 1, 1) = 1

#### Итого: выбраем конфигурацию с 2 HDD на 250 GB


### Медиа

Сapacity = 64 MB/s * 86 400 * 365 = 2000 TB
Ожидаемый трафик = 64 MB/s + 5.5 GB/s + 28 GB/s = 33.5 GB/s
Ожидаемый RPS = 8 RPS + 695 RPS + 1158 RPS = 1861 RPS

#### НDD
Disks_for_capacity = 2000 TB / 32 TB = 63 Disk
Disks_for_throughput = 33.5 GB/s / 100 MB/s = 344 Disk
Disks_for_iops = 1861 / 100 = 19 Disk
Disks = max(63, 344, 19) = 344

#### SSD (SATA) 
Disks_for_capacity = 2000 TB / 100 ТБ = 20 Disk
Disks_for_throughput = 33.5 GB/s / 500 MB/s = 69 Disk
Disks_for_iops = 1861 / 1000 = 2 Disk
Disks = max(20, 69, 2) = 69

#### SSD (nVME) 
Disks_for_capacity = 2000 TB / 30 ТБ = 67 Disk
Disks_for_throughput =  33.5 GB/s /  3 GB/s = 12 Disk
Disks_for_iops = 1861 / 10000 = 1 Disk
Disks = max(67, 12, 1) = 67

#### Итого: выбраем конфигурацию с 67 SSD (nVME) на 30 TB
Поскольку бюджет считается не ограниченым
